# ADR-0007: next-intl, Polish source language

- Status: Proposed

## Decision
`next-intl` with locale-prefixed routing (`/pl`, later `/en`, `/uk`, `/ru`), ICU messages in `messages/<locale>.json`, no user-facing strings inline in components. Service names and descriptions live in `service_translation` / `variant` label translations in the database. A CI check ensures every enabled locale has every key. Fonts must support Latin Extended and Cyrillic from the start. Emails are localized.

## Consequences
+ Adding a language is translation work, not refactoring.
− Slightly more ceremony for every string; accepted.
